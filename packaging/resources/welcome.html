NTFS4Mac

by Vahid Zekic · github.com/vahidzekic/ntfs4mac

Read-write NTFS for macOS in user space, built on Apple's FSKit and libntfs-3g.

This installs:

  • /Applications/NTFS4Mac.app with the FSKit file-system extension
  • /Library/Filesystems/ntfs4mac.fs, which adds NTFS to Disk Utility's Erase › Format menu

Requirements: macOS 15.4 or later (15.6+ recommended), Intel or Apple Silicon.

Warning: this is early software. Back up anything important before writing to an NTFS disk, and do not write to disks of a hibernated Windows (turn off Fast Startup in Windows first).
