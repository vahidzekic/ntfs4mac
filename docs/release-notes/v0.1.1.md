# NTFS4Mac 0.1.1 (preview)

By **Vahid Zekic** · https://github.com/vahidzekic/ntfs4mac

**Universal installer for Intel and Apple Silicon Macs** (tested on an Intel
Mac with macOS 26.5 and an M4 MacBook Air with macOS 15.7).

> Preview software. Back up your data before writing to an NTFS disk, and do
> not write to the disk of a hibernated Windows (disable Fast Startup).

## What's new
- **Apple Silicon.** One universal `NTFS4Mac-0.1.1.pkg` for all Macs.
- **Disk Utility on macOS 15 fixed.** Erase › Format › NTFS and
  `diskutil eraseDisk NTFS4Mac …` failed with "File system formatter failed"
  (-69832) on macOS 15. The format and check helpers now run the FSKit tools
  as the logged-in user there.

## Install
1. Download `NTFS4Mac-0.1.1.pkg` and open it. It replaces 0.1.0.
2. Enable the extension under **System Settings › General › Login Items &
   Extensions › By Category › File System Extensions (ⓘ) › NTFS (ntfs4mac)**.
3. Format a disk as **NTFS** in Disk Utility, or connect an NTFS disk.

Requires macOS 15.4 or later.

## Known issues
- On macOS 15 the NTFS4Mac app can show "Not registered with FSKit" even
  when the extension is enabled and working.
- See also the [CHANGELOG](https://github.com/vahidzekic/ntfs4mac/blob/main/CHANGELOG.md).
